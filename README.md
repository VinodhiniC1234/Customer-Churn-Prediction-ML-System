# 📊 Customer Churn Prediction System

A Machine Learning project that predicts whether a customer will churn (leave the service) based on their usage patterns and account details.

---

## 🚀 Project Overview

Customer churn is a major problem for businesses. This project uses Machine Learning to analyze customer data and predict churn, helping companies take preventive actions to retain customers.

---

## 🎯 Objective

- Predict whether a customer will churn (Yes/No)
- Identify key factors affecting churn
- Build an end-to-end Machine Learning pipeline
- Deploy a simple web app using Streamlit

---

## 🧠 Machine Learning Model

- Algorithm: Logistic Regression / Random Forest
- Problem Type: Binary Classification
- Target Variable: Churn
